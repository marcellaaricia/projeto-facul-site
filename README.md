## ✨ Sobre o projeto

Este repositório contém o site desenvolvido para a **atividade prática de Negócios Digitais**, cujo objetivo era construir a presença online de um negócio fictício e simular como ficaria seu funcionamento digital.

A **Arícia Nails** é um estúdio de beleza e estética voltado para serviços de unhas — alongamento, esmaltação, nail art e cuidados em geral. O site foi pensado como se fosse a vitrine digital real do negócio: apresenta a identidade da marca, os serviços oferecidos, um portfólio de trabalhos e um caminho claro para o agendamento.

> A proposta é oferecer uma experiência digital simples e acessível, aproximando a cliente do negócio antes mesmo de ela chegar ao salão.

<br>

## 🖥️ Páginas do site

| Seção | O que apresenta |
|---|---|
| **Início** | Apresentação da marca e chamada para agendamento |
| **Sobre** | História e valores da Arícia Nails |
| **Serviços** | Lista de serviços com descrição e preço |
| **Galeria** | Portfólio visual dos trabalhos |
| **Agendamento** | Passo a passo de como marcar um horário |
| **Contato** | WhatsApp, Instagram, e-mail e localização |

<br>

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura semântica do site
- **CSS3** — estilização, responsividade e identidade visual
- **JavaScript** — apenas para o menu mobile
- **GitHub Pages** — hospedagem gratuita do projeto

Nenhum framework ou build tool foi necessário — o site roda direto do arquivo `index.html`.

## 🎓 Atividade prática

Para esta atividade, foi desenvolvido um site para a Arícia Nails, um negócio digital voltado para serviços de beleza e nail art, apresentando sua identidade, serviços, portfólio, formas de contato e possibilidade de agendamento.
